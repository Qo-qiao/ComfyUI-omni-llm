# H3Image 提示词编写指南

将想法、简报、现有提示词和参考图转化为可直接使用的 H3Image 提示词。

## 工作流程

1. 确定模式：纯文本生成图像使用 T2I；当需要保留、修改或借用参考图内容（包括构建新构图）时使用 Edit。
2. 阅读对应指南及其示例：
   - [T2I](references/t2i-zh.txt)：根据文本构建图像。
   - [Edit](references/edit-zh.txt)：编写单段式“来源—关系—变化”提示词。按提供顺序检查相关参考图。
3. 将简报发展为具体的可见内容，并补全未指定的普通细节。对于现有提示词，应用所要求的修改，同时保留其他约束。
4. 仅在缺失信息导致无法写出有用提示词时提问。不要要求请求你代写的人先提供完成稿，也不要为填补证据空白而编造来源事实。
5. 对照用户的内容、确切措辞、数量、空间关系和排除项检查最终提示词。
6. 当宿主或下游工具需要生成设置时，单独给出宽高比。保留明确比例，或根据要求的尺寸推导。

## 图像模式

### T2I

根据文本构建完整的场景或设计成品。选择清晰的视觉焦点，遵循指定的实体、数量、风格、媒介和布局，只描述图像中出现的内容。使用 `references/t2i-zh.txt` 中的构图、物理可读性和成品补全规则。

### Edit

编写一个连续的纯文本段落：先定义每个参考来源，再说明目标以及每个来源与目标的关系，最后补全发生变化或新增的内容。按提供顺序使用 `<Picture N>`，并在整段提示词中保持 `<Subject N>` 稳定。不要输出指南中的章节标题，也不要写成编辑命令。

## 输出规则

- 直接交付提示词本身。本技能只编写提示词，不生成图像。
- 使用英文进行视觉叙述；可见文字和委托撰写的文案保留其要求的语言。
- T2I 描述按自然方式组织。Edit 遵循指南的单段式“来源—关系—变化”结构。
- 按用户要求精确保留文字内容、数量、空间关系和排除项；不要编造真实统计数据、价格、认证或规格。

## 提升效果的技巧

- 先确立主构图，再添加场景元素；根据交付物及其内容选择取景。
- 除非要求表现序列，否则保持单一凝固瞬间，并确保接触关系、视线、画面方向和视角一致。
- 为每个要求的区域提供可检查的内容：实际文案、图表坐标轴与单位、UI 状态或图示标签。
- 使用具体的视觉选择，而不是泛泛的质量宣称、隐藏背景故事或额外的主要主体。
- 在 Edit 模式下，默认保留未提及的内容；完全保留的陈述要严格限定在已定义范围内。
