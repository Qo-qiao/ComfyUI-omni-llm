# MOSS-Image 提示词增强器

把用户的想法变成 MOSS-Image 可直接消费的具体画面描述，作为其正向提示词。创意决策由你完成；坐标运算与序列化由随附的 Python 工具处理。本技能从不提交图像生成，也不发布任何内容。

## 选择交付物

用户明确要求 caption 或 Layout 时照办。否则：普通场景、照片、插画用 caption；需要精确文字排位、海报、多个面板或受控物体关系时用 Layout——画面细节丰富并不自动等于需要 Layout。

保留用户的主体、数量、关系、媒介、风格、排除项与预期可见文字。普通创意空缺自行补齐；只有缺失的决策会实质改变图像时才提问。不要把用户没提供的事实性活动细节或规格编造出来。

描述性散文默认用英文（除非用户指定输出语言）。可见文字按原文原样保留，包括标点、大小写与要求的换行。指令中的引号句子不一定是需要渲染的文字：区分"可见文字"与"参考材料/约束"。

## 构思画面

描述可见选择：主体与动作、相关外观、场景、镜头/取景、媒介、光线、材质、色调与情绪。在能让画面更具体处增加细节。避免冗余画质词、未要求的风格改动、随意字数预算与不可见的过程笔记。极简需求保持极简；丰富需求充分展开，但不要套用通用的"标题/主视觉/页脚"模板。

设计类图像要把信息与图像组合考虑：确立阅读顺序、相对显著性、连贯分组与选定像素上的可读文字。写出实际文案，而不是"headline here"之类的占位符。不要从参考图引入无关名称、水印或文案。参考图有用时使用；除非事实准确性需要或用户要求，外部检索不是必须的。

## Caption（画面描述）

写成连贯散文：空间关系用文字表达，可见文字精确引用。可以分段；不要为了"看起来结构化"往 caption 里塞坐标或布局字段。用代码块交付，便于直接粘贴进 MOSS-Image 正向提示词。

## Layout（排版布局）

写出可读的 JSON 草稿：`summary`、扁平 `items` 数组、具体 `width` 与 `height`、`bbox_coord_space="abs"`、`bbox_format="xyxy"`。

**先加载 schema 再动笔——绝不凭记忆起草。** 在状态标记的 `load_references` 中请求 `references/layout.md`，等它出现在已加载列表后再写任何 Layout 草稿。

**草稿框使用 `[x_min,y_min,x_max,y_max]`，单位为实际像素，原点在画布左上角。** x 限定在 `0..width`，y 限定在 `0..height`。不要用归一化坐标，不要手工居中、重排或量化坐标框。

尊重给定尺寸。只有宽高比时，选择兼容的像素尺寸；两者都没有时，用 1024×1024，除非所请求的媒介暗示其他形状。MOSS-Image 尺寸必须是 16 的正整数倍。显式尺寸不兼容时不要悄悄改动，要指出冲突。图像生成工作流中使用相同的宽高。

坐标框只用于连贯的可见单元，仅在独立排位确实重要时才拆分。分组应保留内容与关系，而非抹除它们。允许自然遮挡与重叠。框是排位标注，不是"画边框/面板/贴纸"的指令。外观写在 caption 里，整体处理写在 `summary.caption`；框要与文字描述的空间关系一致。文字条目的 `text` 字段保留精确可见字符串。

## 编译与交付

把草稿 JSON 保存到工作文件，然后运行与本 SKILL.md 同目录的工具。脚本路径从技能位置解析（`skills/moss-image/scripts/`），不要用用户的工作目录：

```bash
python skills/moss-image/scripts/compile_prompt.py draft.json --output prompt.txt
```

保持可编辑 JSON 草稿与编译输出分离。交付前读取结果，检查主体、精确文字、预期几何与所选画布。编译报错就在草稿里修正后重跑；不要手工编写居中坐标来绕过失败的转换——模型绝不能自己计算 `abs_centralized` / `yxyx` 坐标。

如果当前环境无法执行 shell 命令，就交付草稿 JSON 加上面的完整编译命令，并说明编译后的提示词需要运行工具获得；绝不输出猜测的居中坐标。

caption 的输出是纯文本。Layout 的输出是单行 JSON：扁平 `items`、整数 `abs_centralized` / `yxyx` 框、不含画布元数据。工具会先把小数像素边缘向内包拢再减去中心。它会拒绝越界或非法的框而不是静默裁剪。字符串中的换行在 JSON 里被转义，在解码文本中仍是真实换行。

用代码块返回可直接粘贴的提示词。Layout 还要在提示词之外注明所需宽×高——模型提示词本身不含这些尺寸。需要内联展示 Layout JSON 时，使用编译输出，不要重新格式化。只有 caption 或编译后的 Layout 属于 MOSS-Image 的正向提示词。
