# 万相提示词公式

来源：《万相AI生视频—使用指南》（通义万相）。提示词描述视频所包含的内容和运动过程；描述越完整、精确和丰富，生成越贴近期望。按任务选公式，只写该任务需要的部分。

## 基础公式

**提示词 = 主体 + 场景 + 运动**

- **主体**：视频内容的主要表现对象——人、动物、植物、物品或非物理真实存在的想象物体。
- **场景**：主体所处环境，包含背景、前景；真实空间或虚构场景。
- **运动**：主体的具体运动和非主体的运动状态——静止、小幅度运动、大幅度运动、局部运动或整体动势。

适用：初次尝试 AI 视频或灵感启发；简单自由的提示词更具想象力。

## 进阶公式

**提示词 = 主体（主体描述）+ 场景（场景描述）+ 运动（运动描述）+ 美学控制 + 风格化**

- **主体描述**：外观特征细节，用形容词或短句列举，如“一位身着少数民族服饰的黑发苗族少女”“一位来自异世界的飞天仙子，身着破旧却华丽的服饰，背后展开一对由废墟碎片构成的奇异翅膀”。
- **场景描述**：环境特征细节。
- **运动描述**：运动的幅度、速率和作用效果，如“猛烈地摇摆”“缓慢地移动”“打碎了玻璃”。
- **美学控制**：光源、光线环境、景别、视角、镜头、运镜——词表见 `style-vocabulary.md`。
- **风格化**：画面风格语言，如“赛博朋克”“勾线插画”“废土风格”——词表见 `style-vocabulary.md`。

## 图生视频公式

**提示词 = 运动 + 运镜**

图像已确定主体、场景与风格，只描述动态过程及运镜需求：

- 结合图像中的元素（人物、动物）描述动态过程，用形容词控制程度与速度（“快速地”“缓慢地”）。
- 有特定镜头要求时写“镜头推进”“镜头左移”；希望镜头不变化时写“固定镜头”强调。

## 声音公式

**提示词 = 主体 + 场景 + 运动 + 声音描述（人声/音效/背景音乐）**

- **人声 = “角色说话的内容” + 情绪 + 语调 + 语速 + 音色 + 口音**
  示例：一个男人在讲脱口秀，他说道："好好学习，天天向上"，语气轻松，语速适中，声音清亮，美式英文。
- **音效 = 音源材质 + 行为 + 环境音**
  示例：一个玻璃小球从桌面掉在木质地面上，发出“砰”的声音，室内安静环境。
- **背景音乐 = 背景音乐/配乐 + 风格**
  示例：雨夜，阴森窄小的走廊，尽头有一扇窗户，配有悬疑风格背景音乐。

声音要素随时间变化的描述要与画面叙事配合；更多类型示例见 `style-vocabulary.md` 声音部分。

## 参考生视频公式

**提示词 = @主角 + 动作 + 台词 + 场景**

- **@主角**：通过 @ 引用参考主角；最多同时参考 2 个主角，每个主角可在提示词不同位置多次引用。
- **动作**：静止、表情情绪变化、肢体动作、外力动作和位移变化等。
- **台词**：主角说话内容，支持单主角说话或多主角对话。
- **场景**：背景和前景，真实或虚构。

示例（A 的参考视频是兔子，B 的参考视频是狗）：

> 这是一个充满童趣的童话场景。@A 在草地上蹦跳着玩耍，@B 在旁边的一颗苹果树下弹奏钢琴，一颗苹果掉到了@B 的头上，@A 开心的指着@B 说：“你要变成科学家了！”。

参考生会参考主角的外观形象、动态特征和音色（如有声音）；主角可以是人物、卡通、宠物、道具等任意类型。

## 主体参考与指代方法

**指代**：用“文件类型+序号”指代参考文件——图片写“**图x**”，视频写“**视频x**”，x 为该文件在该类型中的序号；图和视频分别计数（可同时存在图1、视频1…），顺序与提交任务时的数组顺序一致。

- **语种写法**：中文提示词写“图1”“视频1”（指代与正文间不需空格）；非中文写“**Image 1**”“**Video 1**”（字母与数字之间有空格，首字母大写）。
- **内容指代**：直接写文件名（“图1在图2里玩耍”），或文件名+物体/场景（“图1的猫在图2的房间里玩耍”），两种均可。

**功能规则**：

- 输入参考：图/视频作为视觉参考，**合计不超过 5 个**；图像支持多视图，常用于参考角色、道具、场景。
- 音色参考：可参考输入视频中的人声音色，或输入音频文件作为参考音色；每个参考最多一个音色；参考文件为视频时音频音色覆盖视频音色；音频仅参考音色，与说话内容无关。
- 首帧图：可与主体参考联合控制——首帧已含待参考主体时搭配强化一致性或加音色参考；首帧未含时可参考视频过程中新出现的主体特征。
- **时长规则**：参考中有视频时支持 **2–10 秒**；不含视频时支持 **2–15 秒**；是否有音频参考不影响时长。

## 多镜头公式（万相 2.6）

**提示词 = 总体描述 + 镜头序号 + 时间戳 + 分镜内容**

- **总体描述**：故事主题、叙述风格、主要情感或核心事件。
- **镜头序号**：每个镜头编号，区分场景/段落顺序。
- **时间戳**：每个镜头的时间范围。
- **分镜内容**：该镜头中角色的具体行为（动作、语言、表情、姿态），参考单镜头写法。

示例：

> 这个故事以第三人称视角，讲述了一个关于放弃与重拾希望的短剧。
> 第1个镜头[0-3秒]一个男孩在操场的角落独自坐着，低头望着手中的信纸，随后轻轻叹气，眼神中透露出迷茫。
> 第2个镜头[4-6秒]硬切转场，固定机位，聚焦于男孩的眼睛，泪光闪烁，带着失落和无助。
> 第3个镜头[7-10秒]硬切转场，场景转至一间简朴的教室。一个女孩眼神温和而坚定，穿着朴素的衣着，面带温和而坚定的笑容，走到男孩的身边安慰他。

## 其他控制关键词（万相 2.7）

公式同多镜头公式。分镜、台词、背景音乐默认由模型自由发挥，需精准控制时显式写出：

- **分镜控制**：写“镜头1 xxxx，镜头2 xxxx”或“镜头1 [0-3秒]xxxx，镜头2 [3-6秒]xxx”，模型会 follow；强控一镜到底写“**生成单镜头**”，英文“**Generate single shot.**”
- **台词控制**：写了 xx说：“xxx”，模型保持该台词内容不变；未写台词则模型自由发挥，要无台词写“**无台词**”，英文“**No dialogue.**”
- **背景音乐控制**：不写模型按题材自行发挥；不要 BGM 写“**无背景音乐**”，英文“**No background music.**”

## 剧情片段结构（智能剧情设计）

一句话故事演绎可按“片段定位 → 场景与表演 → 台词 → 画面基调”的结构写（万相 2.7）：

> 这是一段以“青春期暗恋试探”为核心的校园电影片段。夕阳斜照操场，两人并肩而立，男同学抱着篮球，目光躲闪地问：“下周的联欢会，你要参加吗？”女同学摆弄着鬓角碎发，试探性地回道：“如果……你也去的话，我就去。”……画面呈现清透自然的暖色调，营造出细腻而克制的青春初恋基调。

常用收尾：“画面呈现出……质感，营造出……的基调。”

## 故事板（多宫格参考）

- 需要使用**参考生模型**：多宫格图是参考图，而非严格对齐的首帧图。
- 提示词按**多分镜形式**描述以匹配宫格内容；无需每个宫格全部描述，模型会自行匹配和发挥镜头内容。
- 结构：`参考图片，<风格与一致性要求，如“图中不要加入文字”>。氛围：… 角色：… 场景：… 分镜脚本：[00-01.5s] 全景：… [01.5-03s] 中景：… [03-04.5s] 中景：…`

## 时间分段运镜写法（一镜到底）

在提示词中按时间段指定镜头运动，配合“一镜到底”约束：

> 一镜到底，电影级高度动态专业运镜，精准还原镜头运动逻辑，起始场景：古风书房，少年手持圆形龙纹玉佩；目标场景：月下古风庭院，天空挂着圆月，核心运镜：前3秒镜头锁定少年手中的圆形玉佩特写，4–7秒镜头跟随玉佩向前推进，玉佩的圆形轮廓、纹理无缝匹配下一场景的圆月，最后3秒镜头拉出至月下古风庭院全景

也可用 `[0-3秒] / [3-5秒] / [5-15秒]` 时间戳分段描述长视频（含转场与穿梭类创意结构）。
