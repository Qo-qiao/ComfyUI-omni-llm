# 万相风格与美学词典

提示词可按维度选用以下词汇补全美学控制与风格化（配合 `prompt-formulas.md` 的进阶/图生/编辑公式）。一次不必用满所有维度，选取与画面相关的项即可。

|---|---|
| 光源类型 | 日光、人工光、月光、实用光、火光、荧光、阴天光、混合光、晴天光 |
| 光线类型 | 柔光、硬光、顶光、侧光、背光、底光、边缘光、剪影、低对比度、高对比度 |
| 时间段 | 白天、夜晚、黄昏、日落、黎明、日出 |
| 景别 | 特写、近景、中景、中近景、中全景、全景、广角 |
| 构图 | 中心构图、平衡构图、左/右侧重构图、对称构图、短边构图 |
| 镜头焦段 | 中焦距、广角、长焦、望远、超广角-鱼眼 |
| 机位角度 | 过肩角度、高角度、低角度、倾斜角度、航拍、俯视角度 |

| 色调 | 暖色调、冷色调、高饱和度、低饱和度 |

示例：“电影级构图，日光，中焦距镜头，暖色调，镜头推进，中景，细节完整。”

## 动态控制

### 运动

街舞、跑步、滑滑板、踢足球、网球、乒乓球、滑雪、篮球、橄榄球、顶碗舞、侧手翻……结合运动学描述物理规律，如“像子弹飞过一样快”“在空中漂浮”。

### 人物情绪

愤怒、恐惧、高兴、悲伤、惊讶。可通过身体细节强化：

- 恐惧：“她的瞳孔因极度恐惧而放大，嘴唇微微颤抖，急促地向后退，双手不停地颤抖。”
- 愤怒：“他的眉头紧锁，拳头紧握，身体因愤怒而颤抖。”
- 高兴：“她的脸上绽放出灿烂的笑容，眼睛闪烁着喜悦的光芒，欢快地跳了起来。”
- 悲伤：“他的眼神黯淡无光，泪水在眼眶中打转，缓缓地低下头，肩膀微微颤抖。”
- 惊讶：“他猛地睁大了眼睛，嘴巴微张，身体不由自主地向后仰。”

### 基础运镜

镜头推进、镜头拉远、镜头向右移动、镜头向左移动、镜头上摇。配合运动方向与速度写“镜头向上摇”“镜头快速推进”；变化不大写“固定镜头”。

### 高级运镜

手持镜头、复合运镜、跟随镜头、环绕运镜。常与时间分段写法组合（见 `prompt-formulas.md`）；另有希区柯克变焦、FPV 俯冲穿越、一镜到底等创意运镜。

## 风格化表现

### 视觉风格

毛毡风格、3D卡通、像素风格、木偶动画、3D游戏、黏土风格、二次元、水彩画、黑白动画、油画风格；编辑场景常用：C4D卡通、扁平插画、low poly、8bit像素、真人电影。

### 2D / 3D 风格描述维度

- **艺术风格**：风格化写实 / 卡通 / 动画化
- **形体比例**：卡通夸张比例 / 半写实比例
- **材质**：风格化 PBR
- **光影**：物理写实 / 风格化写实

写法示例：“这是一段皮克斯风格的3D卡通动画电影片段，夸张的头身比例，圆润大眼睛，风格化次表面散射皮肤材质，全局光照配合轮廓光与三点布光，故事讲述……”

### 特效镜头

移轴摄影、延时拍摄。

## 声音类型

| 类型 | 可选要素 |
|---|---|
| 人声 | 单人说话、多人对话、音色、方言、唱歌、rap |
| 音效 | 脚步声、敲门声、物体坠落、撞击声、火焰燃烧声、游戏音效、电子音效、ASMR、动物声音、键盘声 |
| 环境音 | 自然环境（风雨雷电、流水鸟鸣）、城市环境（车流人声）、特定空间（室内安静、山洞回声） |
| 背景音乐 | 情绪音乐、卡点音乐、轻音乐 |

要素写法见 `prompt-formulas.md` 声音公式（人声/音效/背景音乐三段式）。
