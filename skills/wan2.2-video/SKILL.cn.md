# 万相视频提示词优化器

把视频想法改写成通义万相（Wan2.2–2.7）期望的提示词：按任务选公式，编辑类任务用简单语义指令，按需补美学与风格词。提示词描述越完整、精确和丰富，生成越贴近期望；图生视频和编辑类任务只写该任务需要的部分，不复述图像/视频已确定的内容。

完整公式、编辑技巧与词典见三个参考文件。动笔前先加载对应的一个。

## 工作流

1. **判定任务类型**——文生视频 / 图生视频 / 参考生（@主角 或 主体参考）/ 视频编辑 / 续写·首尾帧 / 故事板（多宫格）/ 带声音生成。
2. **选公式**（[prompt-formulas.md](references/prompt-formulas.md)）：

   | 任务 | 公式 |
   |---|---|
   | 文生（基础） | 主体 + 场景 + 运动 |
   | 文生（进阶） | 主体 + 场景 + 运动 + 美学控制 + 风格化 |
   | 图生视频 | 运动 + 运镜 |
   | 带声音 | 主体 + 场景 + 运动 + 声音描述（人声/音效/BGM） |
   | 参考生 | @主角 + 动作 + 台词 + 场景 |
   | 多镜头（2.6） | 总体描述 + 镜头序号 + 时间戳 + 分镜内容 |
   | 剧情片段 / 故事板 | 分镜脚本式结构或“这是一段以…为核心的电影片段” |

3. **编辑类任务**（[video-editing.md](references/video-editing.md)）——用简单清晰的文字描述要修改的语义内容；需要保留原样时补“其他保持不变”，改台词写“保持人物音色和语气”并加引号。
4. **补词典**（[style-vocabulary.md](references/style-vocabulary.md)）——按需选取光源、光线、时间段、景别、构图、焦段、机位、镜头、色调、运动、情绪、运镜、风格化、声音词；只取与画面相关的维度，不必用满。
5. **加版本控制关键词**——需要时显式写“生成单镜头 / Generate single shot.”“无台词 / No dialogue.”“无背景音乐 / No background music.”（万相 2.7）。
6. **对照自检清单**校验，修订一次，只返回修订后的提示词。

## 语言与指代规则

- 中文需求写中文提示词，英文需求写英文；对白加引号。
- 引用图片/视频：中文写“图1、视频1”（与正文间不加空格），英文写“Image 1、Video 1”（字母数字间空格、首字母大写）；序号与提交顺序一致，图和视频分别计数；合计不超过 5 个参考。
- 参考生用 @A/@B 指代主角（最多 2 个主角，可多次引用）。

## 自检清单

- 选对公式，公式要素齐全（对应任务没有的要素才省略）
- 图生视频/编辑任务只写增量，不复述已确定的主体、场景、风格
- 编辑指令简单明确；保留原样写“其他保持不变”；改台词写“保持人物音色和语气”
- 指代序号与提交顺序一致、与正文语言一致
- 多镜头/分镜含镜头序号与时间戳；续写只描述动态变化，不与驱动音频同用
- 人声按“内容+情绪+语调+语速+音色+口音”、音效按“音源+行为+环境”、BGM 按“配乐+风格”写全
- 对白加引号；无台词/无 BGM/单镜头等控制关键词按需显式写出
- 美学与风格词只取相关维度，描述之间不自相矛盾

## 输出

直接给出可复制的提示词，另附至多两行说明：任务类型/所用公式与版本关键词。用户要 JSON 时只输出 `{"prompt": "..."}`。

不编造模型行为结论；内容以《万相AI生视频—使用指南》（通义万相）为准。
