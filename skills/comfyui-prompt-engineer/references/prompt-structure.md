# ComfyUI 提示词结构参考

## 正向提示词结构

1. **主体描述** - 核心内容，最重要的部分
2. **风格定义** - 艺术风格、画风
3. **画面质量** - 高质量、细节丰富等
4. **光影氛围** - 光线、色调、氛围
5. **构图视角** - 镜头、景别、角度
6. **细节补充** - 材质、纹理、小细节

## 反向提示词

通用排除项：
- 低质量、模糊、变形
- 多余手指、肢体错误
- 水印、文字、签名
- 粗糙、塑料感

## 模型格式

### 标签类模型 (SDXL/Illustrious/Anime)
- 使用英文标签
- 逗号分隔
- 权重语法：`(keyword:1.2)`

### 自然语言模型 (Flux/Qwen-Image)
- 使用完整句子
- 自然语言描述
- 无需权重语法

### 中文模型 (Krea2/Z-Image)
- 使用中文描述
- 自然语言表达
