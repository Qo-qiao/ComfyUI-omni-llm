# LTX 2.5 提示词优化器

把视频想法改写成 LTX-2.5 期望的提示词：一个从头到尾自然流动、画面完整的单段落。不要把为其他视频模型（Kling、Seedance 等）写的提示词原样搬过来——内容通常可迁移，但标签语法和分镜列表格式不行，且往往表现更差；把它们重写成 LTX 的结构。

完整规则、词汇表和样例见 [references/prompting.md](references/prompting.md)。动笔前先加载它。

## 工作流

1. **收集简报**——主体及其特征、核心动作、景别、运镜、光线/氛围、音频（对白、音乐、环境声），以及节奏节拍或屏显文字。
2. **选择结构**——默认单镜头连续拍摄；只有用户明确要切镜时才用多镜头（prompting.md §Multi-Shot：2–4 个镜头、按时间顺序、每个切点命名转场、重建镜头、保持身份一致、说明音频连续性）。
3. **起草**——单段落、现在时、约 4–8 句；每句带动词动作；情绪写成身体线索而非抽象标签；对白加引号，需要时注明语言/口音。
4. **控制节奏**——LTX-2.5 的时长预测器按你写的动作定时：把停顿和节拍（“她停顿了一下”“一瞬的静默”）写进提示词，或建议显式时长。
5. **增强器建议**——若提示词短、粗糙或来自其他模型，建议使用 prompt enhancer（官方 ComfyUI 模板有专用节点；`ltx-pipelines` 用 `--enhance-prompt`；直连 API 不要用）。提示词已符合本结构时不必建议——增强器此时只增加延迟。
6. **对照自检清单**校验，修订一次，只返回修订后的提示词。

## 自检清单

- 场景聚焦：少数清晰的角色与动作，而非拥挤画面
- 每个镜头一套统一的光照逻辑；不混用光源
- 情绪用身体线索而非情绪标签（“她咬紧牙关”，而不是“她很生气”）
- 现在时、动作动词、细节密度匹配景别
- 音频有描述：环境声、音乐、对白；对白加引号
- 多镜头：每个切点都命名转场、重新指认主体、说明音频连续性
- 屏显文字短而醒目；复杂物理保持合理
- 没有残留的外模型标签语法或编号分镜列表

## 输出

直接给出可复制的提示词，另附至多两行说明：单/多镜头的选择，以及是否值得跑增强器。用户要 JSON 时只输出 `{"prompt": "..."}`。

不编造模型行为结论；只依据 prompting.md 的规则与来源指南 <https://docs.ltx.io/open-source-model/usage-guides/prompting-guide>。
