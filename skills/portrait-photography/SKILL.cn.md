# 人像摄影提示词编写（专业版）

将用户的人像拍摄想法，以职业人像摄影师的**拍摄脚本思维**转写为可直接用于 Z-Image、Krea 2 等新一代生图模型的提示词。

两大核心原则：

1. **真实感优先**——让生成结果像一张真实相机拍出来的照片，而不是 AI 的"完美假图"。
2. **模型友好**——自然语言叙述流、关键信息前置、具体名词优于抽象形容词、精确摄影词汇压制 AI 味。

## 一、编写流程（四步）

1. **确认四要素**：主体（谁）、场景（哪里）、光线（何时何光）、风格（什么调性的片子）。用户未指定的维度按"手机抓拍风"默认值填充，并在交付时说明默认项。
2. **先定光线**：摄影师思维中光源决定一切——先定光质（硬/柔）→ 光向 → 色温，再推导色调、阴影、肤色与曝光。
3. **选镜头与景别**：焦段决定虚化、压缩与透视，景别决定叙事量。
4. **套用输出模板 → 自检清单 → 交付**。

## 二、输出格式（按需求三选一）

### A. 精简版（默认 · 推荐 Z-Image / Krea 2）

一段式自然语言，**80-150 字**，按重要度递减排序：

```
身份锁定（年龄+性别+发型发色+面容特征+妆容，约25字）
→ 服饰关键（1-2件+面料+颜色饱和度限定，约15字）
→ 动作与心理瞬间（姿态支点+被捕捉的表情，约20字）
→ 光线（时段+方向+光质+色温感受，约20字）
→ 镜头与构图（焦段+景别+机位+主体位置+偏斜度，约25字）
→ 环境与质感（1-2个材质细节+虚化方式，约15字）
→ 风格锚点+真实感细节（直出/胶片+1-2个反AI味细节，约15字）
```

硬性规则：

- **主体身份必须出现在句首**——模型对先出现的特征加权更高。
- 每个维度只选 2-3 个最强信号，全部罗列会互相稀释。
- 具体名词 > 抽象形容词："瓜子脸、深棕长卷发、淡妆" 远强于 "年轻美女"。
- 精确摄影词汇（焦段、胶片型号、光比、色温）比"唯美""高级感"等情绪词更能压制 AI 味与默认网红脸。
- 器材参数用描述性语言而非罗列："85mm 人像镜头，浅景深焦点落在眼睛"，不写 "f/1.4, ISO 200"。

### B. 完整版（十维结构）

用户明确要求结构化长提示词时使用。按以下顺序每维一段，中文小标题起头：

1. **主体**：年龄段、性别、发型发色、发丝动态（风吹、贴脸颊、皮筋松脱）；妆容（素颜/淡妆）；皮肤质感（真实毛孔+环境成因的油光/汗渍/泛红，注明成因）；面容有特征而非完美；表情与心理状态绑定场景语境（通勤、等人、午休）。
2. **服饰**：面料工艺（棉、针织罗纹、缎面、呢料）+ 穿着时间痕迹（坐姿折痕、扯松的领带、卷起的袖口）+ 环境互动（汗渍反光、鞋面划痕沾泥）+ 逐件限定颜色饱和度（如冷红、灰蓝）。
3. **姿态与动作**：重心与支点 + 逐侧肢体分解 + 手部微动作 + 心理外化（肩膀内扣、防御性前倾）。
4. **背景**：具体环境+材质细节 + 发光体 + 动态元素（运动模糊）+ 虚化人物剪影。
5. **构图**：视角、主体位置、一侧留白纵深、头顶 15% 呼吸空间、微偏斜 2-3 度模拟手持。
6. **光影**：光源→光质→光向→色温→阴影分布→曝光策略（高光不过曝或轻微过曝）→轻微噪点感。
7. **层次与质感**：前景/中景/背景三层，各层材质与光学特征（边缘色散、轻微暗角）。
8. **色彩方案**：光源主导色调 + 逐项色彩限定 + 冷暖点缀 + 整体调性锚点（手机自动白平衡的真实表现）。
9. **氛围与风格**：拍摄者身份想象（朋友悄悄按下快门）+ 负面约束（无摆拍痕迹、无滤镜感、无水印边框）。
10. **写实感参考说明**：2-3 句点名本组重点使用的真实感技巧。

### C. 组照模式（3-12 张）

人物一致性是第一目标：

- **身份锁定段**（发型+面容+妆容+核心服饰）原样复制到每条提示词开头，一字不改。
- 每张只变换四个变量：**光线**（侧光/逆光/柔光/冷暖交替轮换）、**景别**（特写/半身/全身/环境）、**动作**、**环境**。
- 6 张组照建议光影轮换：上午侧光 → 树缝光斑 → 黄金时刻逆光 → 阴天柔光 → 45° 窗光 → 蓝调/冷暖交替。

## 三、模型适配

### Z-Image（Turbo）

- 中文原生优化，直接中文输出
- 推荐结构："主体描述 + 艺术风格 + 环境氛围 + 构图视角"
- 对具体面部特征描述响应好

### Krea 2

- 偏好自然语言场景叙事（如"金色午后光洒在她脸上"这类句子）
- 结构：subject + scene + composition + lighting + mood + medium/style + technical detail
- 长句叙述优于碎片标签

### SDXL / Flux 等英文模型

- 切换英文输出，用 [bilingual-terms.md](references/bilingual-terms.md) 术语映射表转换

### 负面提示词模板（通用英文）

```
(low quality, worst quality), plastic skin, over-smoothed skin, airbrushed face, deformed hands, extra fingers, watermark, text, logo, oversaturated, cartoon, anime, 3d render
```

中文模型（如 Z-Image）可省略负面提示词，或简写："无水印、无文字、无塑料感皮肤、无多余手指"。

## 五、安全与合规

- 人像主体默认为成年人；涉及未成年主体时只做自然、日常、得体的描述，禁止任何性化或暗示性细节。
- 不复刻真实公众人物面容。
- 涉及"成熟性感、凸显身材"类需求时，用时装摄影语言表达（优雅修身、缎面吊带长裙、针织连衣裙、锁骨与肩线线条），保持写真级质感，避免露骨描述。

## 完整示例（精简版 · Z-Image / Krea 2 格式）

### 示例一：自然光 · 树林环境人像

> 25岁女生，黑长直发微乱，几缕碎发贴脸颊，素颜有真实毛孔，穿米白棉质衬衫与灰蓝百褶裙，坐在横倒枯树干上，手肘撑膝掌心托腮，目光看向镜头，表情松弛。下午四点自然光从左侧45°斜射，明暗过渡柔和。85mm人像镜头，浅景深焦点落在眼睛，半身景别，人物偏左，画面微偏斜2度。背景树缝光斑与落叶虚化，衬衫有自然坐姿褶皱，鞋头沾干泥点，手机直出感，无滤镜无水印。

写实感要点：树缝光斑、坐姿褶皱、微偏斜构图、具体面部特征压制默认脸。

### 示例二：人造光 · 地铁车厢通勤

> 22岁女生，深棕长卷发被地铁风吹向后方，淡妆，皮肤有真实毛孔与轻微油光，穿白色无袖衬衫（领口微松）与藏蓝百褶裙，靠坐地铁座椅，双腿并拢微侧，双手放腿上握着手机，拇指停在屏幕上方未滑动，表情平静带一丝疲惫。车厢荧光灯冷白顶光约5000K，眼窝与鼻下有自然顶光阴影，车窗隧道灯光呈运动模糊光带掠过。手机主摄26mm直出，平视微偏斜2度，座椅塑料磨砂质感为前景，背景乘客模糊剪影，冷白调肤色带窗外零星暖色点缀，无滤镜无水印。

写实感要点：顶光面部阴影、运动模糊光带、环境性油光、模糊乘客剪影。
