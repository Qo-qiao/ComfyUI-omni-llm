## 负面提示词（通用英文）

```
(low quality, worst quality), plastic skin, over-smoothed skin, airbrushed face, deformed hands, extra fingers, watermark, text, logo, oversaturated, cartoon, anime, 3d render
```

中文模型可简化为：
```
无水印、无文字、无塑料感皮肤、无多余手指
```
