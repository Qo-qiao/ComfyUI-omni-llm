## 必检项目

### 主体与身份

- [ ] 主体身份是否前置且具体（年龄/发型/面容/妆容）
- [ ] 是否写明了具体面部特征（避免默认网红脸）
- [ ] 发型发色是否具体（长度、颜色、动态状态）

### 光线与色温

- [ ] 光源是否唯一且明确（时段+方向+光质）
- [ ] 色调是否由光源推导
- [ ] 是否有眼神光描述
- [ ] 深发色+深背景是否补写发丝轮廓光

### 镜头与构图

- [ ] 镜头语言是否定了焦段与景别
- [ ] 主体位置是否明确（偏左/偏右/居中）
- [ ] 是否有微偏斜或手持感描述

### 姿态与动作

- [ ] 动作是否有心理状态与瞬间感
- [ ] 手部是否有处安放
- [ ] 姿态是否自然（非僵硬摆拍）

### 真实感

- [ ] 真实感技巧是否 ≥5 项
- [ ] 是否有服装褶皱/磨损细节
- [ ] 是否有环境互动细节

### 负面约束

- [ ] 是否有负面约束（无滤镜/无水印）
- [ ] 同条内无矛盾描述

### 长度

- [ ] 精简版是否在 80-150 字内
- [ ] 完整版每维度是否简洁

---

## 组照模式检查

- [ ] 身份锁定段是否逐字一致复制到每条开头
- [ ] 每张是否只变换四个变量（光线/景别/动作/环境）
- [ ] 光影是否有轮换变化
- [ ] 人物一致性是否保持

---

## 质量等级

| 等级 | 标准 | 处理 |
|------|------|------|
| **A 级** | 所有检查项通过 | 直接交付 |
| **B 级** | 1-2 项小问题 | 修改后交付 |
| **C 级** | 3 项以上问题 | 重新编写 |
| **D 级** | 身份不前置、光线不明确 | 废弃重写 |

## 常见问题速查

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 生成结果像网红脸 | 未写具体面部特征 | 添加瓜子脸、内双、小雀斑等 |
| 皮肤有塑料感 | 未写皮肤质感 | 添加真实毛孔、环境性油光 |
| 头发糊进背景 | 未写发丝轮廓光 | 添加 rim light on hair |
| 构图太"完美" | 未写微偏斜 | 添加 slightly tilted 2 degrees |
| 动作僵硬 | 未写瞬间感 | 添加动作进行时描述 |
| 服装太干净 | 未写褶皱细节 | 添加坐姿折痕、汗渍反光 |
